MongoDB Assignment-
Exercise 1-
1. Online Banking System → SQL

Justification:
Requires ACID properties for secure and accurate transactions (e.g., money transfers). Data is highly structured and needs strong consistency.

2. Social Media Platform → NoSQL

Justification:
Handles large volumes of unstructured data (posts, comments, likes). Needs high scalability and flexible schema.

3. Real-Time Chat Application → NoSQL

Justification:
Requires low latency and high throughput. Data is fast-growing and semi-structured, making NoSQL suitable.

4. Hospital Patient Records → SQL

Justification:
Needs high accuracy, consistency, and integrity. Data is structured and must comply with strict regulations.

5. IoT Sensor Data Collection → NoSQL

Justification:
Deals with high-volume, time-series data from sensors. Requires scalability and flexible schema.
